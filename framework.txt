====================================================
Embedded Framework Roadmap - Month 1
====================================================

Goal:
Establish a solid foundation for the Embedded Framework.
Focus on architecture, build system, and the first reusable modules.
Target effort: ~2 hours/day (~10 hours/week)

----------------------------------------------------
Week 1 - Project Foundation
----------------------------------------------------

Objectives:
- Create Git repository
- Create workspace structure
- Setup CMake project hierarchy
- Create first BoardPackage
- Generate STM32CubeMX project
- Build firmware successfully

Tasks:
[ ] Create Workspace folder structure
[ ] Create EmbeddedFramework folder
[ ] Create BoardPackages folder
[ ] Create Projects folder
[ ] Create top-level CMakeLists.txt
[ ] Generate STM32CubeMX project
[ ] Copy generated files into BoardPackages/nucleo_l433/generated
[ ] Create board folder
[ ] Build firmware successfully
[ ] Flash firmware to the board

Deliverable:
✓ Empty firmware builds and flashes successfully.

----------------------------------------------------
Week 2 - GPIO Platform Abstraction Layer
----------------------------------------------------

Objectives:
- Design the PAL GPIO interface
- Implement STM32 GPIO backend
- Blink LED using PAL only

Tasks:
[ ] Create pal/gpio/include/gpio.h
[ ] Create platform/ports/stm32/gpio
[ ] Implement PAL_GPIO_Init()
[ ] Implement PAL_GPIO_Write()
[ ] Implement PAL_GPIO_Read()
[ ] Implement PAL_GPIO_Toggle()
[ ] Create board pin definitions
[ ] Blink LED through PAL

Deliverable:
✓ LED blinking without calling HAL directly from application code.

----------------------------------------------------
Week 3 - UART PAL + Logger
----------------------------------------------------

Objectives:
- Implement UART abstraction
- Build reusable logging service

Tasks:
[ ] Design UART API
[ ] Implement STM32 UART backend
[ ] Create Logger service
[ ] Redirect logger output to UART
[ ] Print startup message
[ ] Add simple log levels (INFO, WARN, ERROR)

Deliverable:
✓ UART communication through PAL.
✓ Logger working on STM32.

----------------------------------------------------
Week 4 - Ring Buffer + CLI Foundation
----------------------------------------------------

Objectives:
- Build reusable Ring Buffer
- Start CLI framework

Tasks:
[ ] Implement Ring Buffer utility
[ ] Unit test Ring Buffer
[ ] Connect UART RX to Ring Buffer
[ ] Parse received commands
[ ] Implement "help" command
[ ] Implement "version" command

Deliverable:
✓ Working UART command-line interface.
